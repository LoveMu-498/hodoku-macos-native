# 从源码构建HoDoKu macOS 原生版

在 Apple Silicon Mac 上克隆仓库或解压 Release 的对应源码，从包含 script、native 的目录运行以下命令。使用可部署到 macOS 11 的 SDK、Xcode 提供的 Swift 工具和 Python 3。构建脚本按固定版本及 SHA-256 准备 Rust arm64 工具链；已有经过验证的缓存会直接复用。

```sh
bash script/build_native_candidate.sh
```

最后一行给出本地签名的应用路径。相邻目录保存 Rust 与 Swift 测试、工作台回归、工具链版本、Mach-O 审计、构建输入和逐文件 SHA-256。在应用目录内运行 `shasum -a 256 -c ../SHA256SUMS` 可校验本次产物。测试使用项目内的隔离数据目录。应用图标从 [Core Graphics 源码](Artwork/AppIcon.swift)生成 16–1024 像素的图层，随包签名，预览为相邻目录的 `app-icon.png`。

打包使用 COPYING、UPSTREAM.md、THIRD_PARTY_NOTICES.md、Swift 项目许可和所选 Rust 工具链的标准库归属文件。原生产品的 Rust 依赖见 native/engine/Cargo.lock。开发用 Java 录制值、题库与回放夹具仅供构建时测试。

## 使用工作台

按 ⌘, 打开设置。选择、勾选和调整数值后即刻生效，点「返回棋盘」可继续当前作答。宽窗用侧栏切换分类，窄窗用顶部的分类菜单。要改变新题的难度、模式或给定数布局，打开「出题与图案」。修改图案后需重新检查，检查通过后用于后续出题。「训练技巧」可指定学习或练习的目标。

- 标题栏中央的五个工具依次对应普通作答、标色、涂鸦、自由链和选框。选「视图 → 自定工具栏…」可加入分析当前线索、当前思路、解题路径、选择技巧、分享棋盘、保存、题目历史、冻结画面或解题摘要，也可重新排列或恢复默认工具栏。
- 从「文件 → 分享棋盘…」或点击顶部、底部的分享按钮，可按格式分享题目或棋盘图片。直接选中一项会打开 macOS 共享面板，可使用 AirDrop 等系统服务。按住 Option 选择同一项会打开保存面板。也可用 ⇧⌘S 将当前题目另存为 HSOL。
- 工具栏下方的操作栏提供数字筛选和当前工具的控件。点数字可筛选棋盘，按住 ⌘ 再点一个数字可加入或移出筛选。标色、涂鸦、自由链和选框在同一位置显示各自的控件。
- 在自由链（L）中，⌘点候选从该处另起一段，已有链段会保留。⌘点旧链尾，再点下一候选，可以接回该段。⇧点候选可把它并入当前链尾的候选组。圆端底带连接同组成员，蓝色外圈标出下一条边的起点。
- 自由链仍在续画时可按 Tab 匹配当前思路，按反引号分析或继续阅读，⇧＋反引号（~）返回上一档。按住中键或 Option 可预览链尾的下一跳。操作栏的实线与虚线图标分别显示当前连通链的双强和双弱接点数。
- 底栏显示作答模式、已填格数、选区坐标及候选或笔记。选中多格可查看共同候选，作答详情还显示合计候选、原题难度和评分。点「技巧」，选中技巧后可直接输入实例的原序号，或用箭头和序号行的滚轮浏览。按住 Option 临时预览，按 A–D 染色、S 框选、H 阅读该实例。选择「默认提示」后可按 H 从首档阅读，F12 查看完整提示。
- 查找提示时，棋盘边缘显示「正在查找步骤…」。找到步骤后，提示面板在右侧打开。当前思路、选择技巧和解题路径也用同一个右侧面板。有足够空间时棋盘保持居中。空间不足时，面板可收窄、棋盘可左移，或由窗口扩宽来减少遮挡。点「−」可暂时收起，点顶部的「提示」或底栏的「展开提示」可回到同一阅读位置。关闭提示后方向键继续移动棋盘选区。读到最后一档，点「应用此步」可将该步的删候选或填数写入盘面。

- 棋盘光标用实点、空心点和短划区分单击、双击及拖动。分析需要补充输入时，消息在工作区边缘短暂显示。涂鸦笔宽用单个圆点表示，点击或在圆点上滚动可切换。在设置中开启「播放操作音效」可听到编辑、复制、粘贴、清除、保存和共享的反馈。手动保存与共享成功后各有独立提示音，自动保存保持安静。

- 在填数模式按住 ⌘ 拖动可矩形多选。底栏的时钟按钮可预览上一步盘面，也可按住 Q。解数结果以短消息显示。
